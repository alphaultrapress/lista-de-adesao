# Ícones

Ícones SVG customizados ou arquivos de ícone do PWA/favicon.

## Sugestão

```
icons/
├── icon-192.png             para manifest PWA
├── icon-512.png             para manifest PWA
└── *.svg                    ícones inline customizados, se houver
```

Os ícones inline da interface (setas, check, etc.) continuam vivendo
como SVG dentro dos componentes — apenas arquivos que precisam ser
referenciados por URL vêm para cá.
